\# EPUB‑WeasyPrint‑PDF

EPUB转PDF书稿级排版工具，纯Python，基于WeasyPrint。

最大程度保留EPUB原始排版观感，输出符合图书出版规范的PDF。



> 不依赖Calibre、不依赖LaTeX。



\## ✨核心特性

\- 保留EPUB原CSS样式、图文布局

\- 镜像装订边距、奇偶页不同页眉、翻口页码

\- 纯净页码计数，前置页不占用正文页码

\- 右手页起章，自动补空白页

\- 自动生成带真实页码的出版目录，自动过滤原书目录页

\- 精细分页防DOM错乱
